# Hệ sinh thái Công cụ cho Nhà phát triển (Developer Tools)

Google cung cấp một loạt các công cụ, ngôn ngữ và nền tảng giúp các nhà phát triển xây dựng ứng dụng chất lượng cao cho web, di động và đám mây.

## 1. Phát triển Ứng dụng Di động
- **Flutter**: [flutter.dev](https://flutter.dev/)
    - **Cách dùng**: Cài đặt SDK Flutter và sử dụng ngôn ngữ Dart để xây dựng ứng dụng cho nhiều nền tảng từ một code base.
- **Firebase Studio**: [firebase.google.com](https://firebase.google.com/) - Môi trường phát triển AI-first giúp xây dựng ứng dụng nhanh chóng.

## 2. Phát triển Web
- **Project IDX**: [idx.google.com](https://idx.google.com/) - IDE dựa trên đám mây tích hợp Gemini để hỗ trợ lập trình.

## 3. Công cụ AI & Agent cho Lập trình viên
- **Jules**: [jules.google](https://jules.google/) - AI agent hỗ trợ quản lý và cải thiện mã nguồn trực tiếp trên các kho lưu trữ GitHub.
- **Google Antigravity CLI**: Công cụ dòng lệnh mạnh mẽ để tạo và triển khai các AI agent nhanh chóng.
- **Gemini Code Assist**: Trợ lý viết mã tích hợp trong VS Code, IntelliJ và các IDE phổ biến.
- **Colab**: [colab.google](https://colab.google/) - Môi trường lập trình Python trên trình duyệt tích hợp sẵn AI.

## 5. Hạ tầng & DevOps
- **Google Cloud SDK**: Bộ công cụ dòng lệnh để quản lý các tài nguyên Google Cloud.
- **Terraform Google Provider**: Hỗ trợ Infrastructure as Code (IaC) cho Google Cloud.
